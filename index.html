O que é o Protocolo HTTP?

O HTTP (Hypertext Transfer Protocol) é a base da comunicação na rede mundial de computadores (World Wide Web). Ele funciona através de um modelo do tipo Cliente-Servidor, onde um navegador (cliente) faz uma requisição para um servidor web, e este responde enviando os arquivos necessários (como códigos HTML, imagens e estilos) para exibir a página na tela.
